**三角洲行動** · 遊戲輔助工具

特勤處製造會在文字頻道發布推薦物品及預估收益。成員可直接閱讀推薦，或開啟詳情查看材料、成本與價格圖。

## 成員：閱讀推薦與詳情

1. 開啟推薦頻道，先查看訊息上的最後更新時間。
2. 閱讀工作台、推薦物品及每小時收益。
3. 點「查看詳情」，在僅自己可見的回覆查看材料、製造成本、收益與價格圖。

:::note[詳情不是即時價格]
詳情來自**該推薦訊息保存的資料**，不是點擊時重新查詢即時價格。若顯示「詳細資料尚未建立」，等待推薦下一次成功更新後再查看。
:::

## 管理者：設定推薦頻道

設定需具備 Discord Administrator 或 Mochi 已授權管理角色，Mochi 需能查看目標頻道、傳送嵌入訊息、附加圖片及更新自己發布的訊息。

1. 到預定的伺服器文字頻道執行 `/manufacture setup`，不需填參數。
2. 閱讀同步結果。成功後，頻道會出現或恢復固定推薦訊息。
3. 檢查最後更新時間及詳情按鈕；若回覆有失敗項目，先檢查頻道權限與錯誤內容。

設定會嘗試取得資料並同步訊息。取得來源失敗時不代表已完成設定；部分訊息失敗時也不代表全部推薦均已更新。

## 手動更新、停用與換頻道

- **立即更新**：`/manufacture refresh` 重新取得來源並同步推薦，需先完成設定且未停用。
- **停止更新**：`/manufacture disable` 停止此伺服器的自動更新，舊推薦訊息保留。
- **更換頻道**：先執行 disable，再到新的文字頻道執行 setup。

其他頻道仍啟用時，setup 會拒絕直接換頻道。舊訊息保留不代表它仍會更新，應以目前設定位置與資料時間判斷。

## 資料時效與限制

自動排程在每小時 **00、30 分（臺北時間）**執行。Bot 當時未就緒時會跳過該次排程，重新啟動本身不會立即查詢來源。

排程執行不代表每次都會編輯 Discord 訊息。當顯示內容未達更新條件時，可能正常略過更新；手動執行 `/manufacture refresh` 也可能得到未變更的結果。

更新會與上次成功顯示的推薦比較：物品、來源或其他顯示資訊改變，或預估每小時收益變動達 **5%** 時，會嘗試更新。較小的收益變動可能暫不反映在訊息上。

距上次成功同步訊息達六小時也是更新判斷條件之一，**不是更新成功的保證**。實際更新仍需要推薦及詳情資料可用，以及 Discord 訊息操作成功。畫面的更新時間不等於每次排程檢查的時間，也不是來源資料即時性的保證。

資料來源會優先嘗試已登入的推薦資料；登入資料不可用或查詢失敗時，改用未登入的備援來源。兩者的推薦及預估收益可能不同，使用備援時訊息會顯示提示。

收益是外部資料提供的估計，並非即時成交價格或獲利保證。備援來源的推薦及收益可能有差異，請同時參考更新時間、來源提示及遊戲內價格。

來源失敗時可能仍保留上次成功的訊息。多次點擊詳情只會讀取保存資料，不會強制刷新。

## 常見問題

### 提示先設定

到目標文字頻道執行 `/manufacture setup`。

### 提示已設定其他頻道

先停用，再到新頻道 setup。

### 詳情尚未建立

待下一次成功更新；管理者也可使用 refresh 嘗試更新。

### 詳情圖片產生失敗

稍後重試，不必反覆重新設定頻道。

### 訊息時間沒有更新

先確認同步結果是否為「未變更」；顯示內容未達更新條件時，訊息時間不變可能是正常情況。

若回覆有失敗項目，或長時間沒有更新，再檢查是否停用、Bot 是否在線及頻道權限；來源錯誤時稍後再試 refresh。

成員在面板加入指定 Emoji 反應即可領取角色，取消自己的反應則撤銷角色。以下先說明領取方式，再說明管理者如何建立面板。

## 成員：領取與撤銷角色

1. 開啟伺服器的角色面板，查看 Emoji 與角色的對應說明。
2. 加入想領取角色的 Emoji 反應，等待身分組更新。
3. 不再需要該角色時，取消自己加入的同一個反應。

不需要輸入 Slash Command。若加入反應後角色沒有更新，先查看下方的權限檢查，不要連續重複點擊。

<span id="使用前確認"></span>

## 管理者：建立面板

設定者需具有 Discord Administrator 或 Mochi 已授權管理角色。先完成下列準備：

- 在伺服器建立要發放的角色，並將 **Mochi 的最高角色移到目標角色上方**。
- 給予 Mochi「管理身分組」權限；目標不能是 `@everyone`。
- 在面板文字頻道允許 Mochi 查看、傳送嵌入訊息、讀取訊息歷史及加入反應。成員需能查看面板並操作反應。

<span id="如何再次取得訊息-id"></span>

### 建立面板並取得訊息 ID

1. 到面板要出現的文字頻道，選擇 `/reaction panel`。
2. 在 `title` 輸入「領取通知角色」；`description` 可填操作說明，也可以省略。
3. 送出後，Mochi 會在頻道發布面板，並在設定回覆顯示「訊息 ID」。
4. **複製並保存回覆中的完整數字 ID**，下一步會用到。不要使用頻道 ID 或整段訊息網址。

### 綁定 Emoji 與角色

1. 選擇 `/reaction add`。
2. 在 `message_id` 貼上剛才複製的面板訊息 ID。
3. 在 `emoji` 輸入要使用的 Emoji，例如 `🎮`。
4. 在 `role` 選取要發放的真實身分組；`label` 可填「遊戲通知」，省略時顯示角色提及。
5. 送出後確認「已新增反應身分組」，並檢查面板是否出現該 Emoji 與角色說明。

成員依面板加入反應後，應取得選定角色。自訂 Emoji 也可以使用，但必須是 Mochi 能存取並加入訊息的 Emoji。

## 調整或停止面板

- `/reaction list`：在 `message_id` 貼上面板 ID，查看目前綁定。
- `/reaction remove`：填入同一面板 ID 與該綁定的 Emoji，移除單一對應。
- `/reaction delete`：填入面板 ID，刪除該面板的全部設定。

:::caution[移除設定不會回收角色]
這些移除操作**不會主動回收已發放的角色，也不會刪除面板訊息或清掉所有反應**。綁定刪除後，再取消反應也不會依該綁定收回角色；需要回收時，管理者應另外處理成員角色。
:::

## 常見問題

### 找不到面板或訊息

檢查 `message_id` 是否為完整純數字，且面板是在同一伺服器透過 `/reaction panel` 建立。若面板訊息已刪除，請重新建立面板及綁定。

### 無法綁定或領取角色

依序檢查 Mochi 的「管理身分組」權限、最高角色位置、目標角色是否存在，以及面板存取權限。若既有反應仍在但角色未取得，修正設定後取消自己的反應，再重新加入。

### 無法加入 Emoji

先確認輸入的是有效 Emoji，且 Mochi 能使用它。自訂 Emoji 失敗時，可先以一般 Emoji 檢查流程是否正常。

客服單 v2 會為案件建立獨立文字頻道，供開單者與客服角色對話。一般成員從面板開始，管理者則負責設定面板、問題類型及客服角色。

## 成員：建立客服單

1. 到伺服器的客服面板，選擇問題類型按鈕。
2. 「直接開單」會建立頻道；「表單開單」則先顯示必填欄位，填完後送出。
3. 從僅自己可見的回覆開啟案件頻道，繼續補充問題。

每位成員在同一伺服器最多同時有 **3 張未關閉案件**。表單最多五欄，每欄必填、最多 500 字元。

:::caution[哪些人可以查看案件]
案件頻道預設不開放給所有成員，開單者、Mochi 及設定的客服角色可存取；具有 Discord Administrator 權限的人也可能存取。不要將它視為只有自己可見的空間，或填入密碼與憑證。
:::

### 提及成員可能新增存取權限

在**開啟中的客服單文字頻道**，開單者或管理者發送訊息並提及其他非機器人成員時，Mochi 會嘗試為其中尚無查看權限的成員新增頻道權限。此處的管理者包含 Discord Administrator 及 Mochi 已授權管理角色；單純具有客服角色、但不符合前述身分的人，不會因此觸發新增。

新增成功後，對方可以查看頻道、傳送訊息及讀取既有訊息，**擴大客服單內容的可見範圍**。提及前請先確認案件資料是否適合讓對方閱讀。已可查看頻道的成員與機器人帳號會被略過；新增權限也需要 Mochi 能調整該頻道的權限。

## 關閉客服單

處理完成後，在案件頻道按關閉按鈕，再於 60 秒內選擇「確認關閉」或「取消」。確認介面只允許發起者操作。

### 兩種關閉入口的權限

- **關閉按鈕**：開單者、管理者或該類客服角色可用。
- **`/ticket-v2 close`**：管理者或該類客服角色可用。只有開單者身分並不足以使用此指令。

這裡的管理者包含 Discord Administrator 及 Mochi 已授權管理角色。

### 關閉後會發生什麼？

正常關閉會先將表單答案與當時可讀取的對話匯出成 CSV，記錄案件關閉狀態，再嘗試刪除頻道。CSV 包含發言者顯示名稱、文字、附件網址與時間；不會另存附件檔案本身，也不是所有 Discord 內容的完整備份。

**關閉案件不等於刪除所有紀錄**。案件資訊與表單答案會保存在案件紀錄，關閉時另產生 CSV 檔案；關單及下載 CSV 都不會清除這些紀錄。CSV 指令只允許管理者使用；開單者或客服角色不會只因能關單就取得下載權限。

**標記關閉與刪除頻道是不同步驟**。Mochi 會先記錄案件已關閉並送出成功回覆，再嘗試刪除 Discord 頻道。因此，即使收到關閉成功回覆，頻道也可能仍然存在，刪除失敗時不一定會有額外錯誤通知。管理者必要時應確認頻道是否仍存在，並檢查其存取權限。若對話匯出失敗，也不要假定案件已完成關閉。

## 管理者：建立可用的客服面板

設定需具備 Administrator 或已授權管理角色。Mochi 需要建立及刪除文字頻道、調整頻道權限、查看與讀取歷史、傳送訊息、嵌入內容及附加檔案的權限。

:::caution[謹慎選擇客服角色]
客服角色會取得案件頻道的查看、傳送訊息與讀取既有訊息等權限，新增角色也會嘗試同步目前開啟中的案件。請只選擇實際負責客服的角色，避免選擇 `@everyone` 或成員範圍過廣的角色，以免讓不應存取案件的成員看到內容。

此設定沒有自動排除這類角色。即使既有頻道同步失敗，角色設定仍可能已保存，請核對回覆與實際頻道權限。
:::

### 先完成一種直接開單流程

1. 在預定的客服面板文字頻道執行 `/ticket-v2 panel`。`content` 可填「請選擇問題類型」，最多 3,500 字元。
2. 選擇 `/ticket-v2 button-add`，在 `name` 填「一般問題」，在 `mode` 選「直接開單」；`style` 可省略，預設灰色。
3. 選擇 `/ticket-v2 role-add`，在 `button_name` 選「一般問題」，在 `role` 選取實際負責的客服身分組。
4. 用 `/ticket-v2 message` 設定開單後的提醒，例如「請描述問題並等待客服回覆」。
5. 從面板按「一般問題」，確認案件建立後，開單者與客服角色都能閱讀並回覆。

新案件會使用面板頻道所在分類（若有）。同一伺服器的按鈕名稱不可重複，最多 25 個，每個名稱最多 80 字元。

### 加入表單開單類型

1. 用 `/ticket-v2 button-add` 新增另一個名稱，在 `mode` 選「表單開單」。
2. 用 `/ticket-v2 field-add` 選擇該 `button_name`，在 `field_name` 輸入第一個欄位名稱。
3. 重複新增需要的欄位，每個名稱最多 45 字元，最多五欄。
4. 用 `/ticket-v2 role-add` 設定該類客服角色，再從面板檢查表單及開單結果。

沒有欄位的表單按鈕不能開單。表單欄位皆為必填短文字，沒有設定成選填或其他欄位型態的參數。

## 調整既有設定

- `/ticket-v2 button-style` 修改按鈕顏色；`button-remove` 刪除開單按鈕，不會關閉既有案件。
- `/ticket-v2 field-add`、`field-remove` 調整表單欄位。
- `/ticket-v2 role-add`、`role-remove` 調整客服角色，並嘗試同步現有開啟中案件；請檢查回覆中的成功與失敗數量。
- `/ticket-v2 rename` 在目前案件頻道修改名稱，系統保留案件編號。
- `/ticket-v2 csv` 以案件編號取得紀錄；用 `user` 找到多筆時，先從回覆取得編號，再查詢該案件。

移除客服角色後，成員仍可能因其他角色、個人覆寫或 Administrator 權限看見頻道；應檢查 Discord 最終權限，而非只看單一角色設定。

移除開單按鈕也不會自動撤銷既有案件的頻道權限。請先確認未結案件的處理方式與存取權限，再刪除按鈕。

## 常見問題

### 按鈕已失效

使用有效面板；管理者可檢查該按鈕是否已刪除。

### 表單尚未設定

先依上方步驟新增欄位，再開單。

### 已達開單上限

先關閉不再需要的案件，再建立新單。

### 不能建立或關閉頻道

檢查 Mochi 的頻道權限。關閉還需讀取歷史並成功匯出對話。

### 找不到 CSV

案件尚未產生紀錄或檔案已不存在時無法取得；請確認編號與關閉結果。

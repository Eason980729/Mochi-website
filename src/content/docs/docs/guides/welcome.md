新成員加入伺服器時，Mochi 會在指定文字頻道送出歡迎訊息。成員不需要執行任何指令；管理者只需設定頻道與文字。

## 使用前確認

Mochi 在目標文字頻道需要「查看頻道」、「傳送訊息」與「嵌入連結」權限。成員本身不需要設定權限或額外操作。

## 設定歡迎頻道與文字

設定者需具有 Discord Administrator 權限，或持有 Mochi 已授權的管理角色。

1. 輸入 `/welcome channel`，在 Discord 的 `channel` 欄位選擇歡迎頻道，然後送出。
2. 收到「已設定歡迎頻道」後，執行 `/welcome message`。
3. 在 `message` 輸入歡迎內容。可以直接填寫：`歡迎 {user} 加入 {server}！`
4. 收到「歡迎訊息已設定」後，設定即會套用至之後加入的成員。

:::note[設定後何時生效]
**預期結果**：下一位成員加入時，指定頻道會出現歡迎訊息，內容帶入成員提及與伺服器名稱，並顯示成員頭像。設定指令本身不會立即發送歡迎訊息，也不會替已加入的成員補發。
:::

### 可使用的替換字

- `{user}`：新成員的 Discord 提及。
- `{server}`：目前伺服器的名稱。

保留英文拼字與大括號。這兩種標記以外的文字會原樣保留。未自訂文字時，預設內容是「歡迎 {user} 加入 {server}！」。

## 變更既有設定

要更換位置，重新執行 `/welcome channel` 選擇另一個文字頻道；要修改內容，重新執行 `/welcome message`。兩個設定彼此獨立，修改文字不會同時更換頻道。

## 沒有收到歡迎訊息？

1. 重新執行 `/welcome channel`，檢查選到的頻道是否仍存在，並確認設定回覆中的頻道正確。
2. 在該頻道檢查 Mochi 的查看、傳送訊息與嵌入連結權限。
3. 確認是在設定完成後有新成員加入；修改設定不會為既有成員觸發歡迎訊息。

若指令回覆權限不足，請使用具有 Administrator 或已授權管理角色的帳號操作；角色名稱叫「管理員」並不等於已獲授權。

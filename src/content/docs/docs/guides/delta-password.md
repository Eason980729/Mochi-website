**三角洲行動** · 遊戲輔助工具

每日密碼會送到指定文字頻道。成員直接閱讀訊息，管理者只需設定發送位置。

## 成員：查看每日訊息

1. 開啟伺服器的每日密碼頻道，找到 Mochi 最新發送的「三角洲今日密碼」。
2. 查看訊息底部的日期與時間，再閱讀對應地圖的密碼欄位。
3. 若某張地圖顯示「密碼：未取得」，代表該次來源沒有提供可用值，不能當成有效密碼。

目前沒有一般成員即時查詢的 Slash Command。請以訊息日期識別當日資料，不要把前一天的訊息當成今天更新。

## 管理者：設定發送頻道

設定需具備 Discord Administrator 或 Mochi 已授權管理角色。

1. 準備一個文字頻道，讓 Mochi 能查看、傳送訊息及嵌入內容。
2. 選擇 `/delta channel`，在 `channel` 選取該頻道。
3. 收到「已設定三角洲密碼頻道」後，確認回覆中的位置正確。
4. 下一次臺北時間 08:00 後，在目標頻道查看發送結果。

:::note[設定不會立即補發]
設定不會立即發送；再次執行指令會更換之後的發送位置。這項功能屬通用功能，但仍須設定頻道。
:::

## 更新時間與發送限制

排程為每日 **臺北時間（Asia/Taipei）08:00**，不是每位成員的當地時間。來源資料取得失敗時，會嘗試發送取得失敗提示；若 Discord 頻道不可用或沒有發送權限，連錯誤提示也可能無法送達。

排程不保證補發錯過的訊息，也不會持續重試至取得密碼。完整資料與實際遊戲內容仍取決於外部來源。

## 常見問題

### 剛設定卻沒有訊息

設定成功只代表發送位置已保存，等待下一次 08:00 排程。

### 只有部分地圖沒有密碼

查看該欄是否為「未取得」，不要自行沿用舊值。

### 沒有收到當日訊息

重新檢查 `/delta channel` 回覆的頻道，以及 Mochi 的查看、發送與嵌入連結權限。Bot 離線或來源失敗也可能導致當次未發送。

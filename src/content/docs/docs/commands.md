## AI 聊天

`/ai chat` 需在已開啟 AI 的伺服器頻道使用。以下記憶操作僅針對本人個人記憶；相關記憶服務需正常可用。

| 指令 | 參數 | 用途 |
| --- | --- | --- |
| `/ai chat` | `message`：文字，必填 | 與 AI 對話，回覆僅自己可見。 |
| `/ai memory` | 無；開啟表單 | 在伺服器內設定個人回覆語氣與固定資訊。 |
| `/ai memories` | 無 | 在伺服器內查看本人的長期記憶。 |
| `/ai forget` | `memory_id`：記憶 ID，必填 | 刪除本人的指定長期記憶。 |

### 對話範例

```text
/ai chat message: 請幫我整理這段文字的重點。
```

上方為輸入格式示例，請將內容換成你的問題。公開對話可在已啟用的文字頻道中提及機器人並輸入內容。

:::caution[回覆可見性與資料]
僅自己可見的回覆仍可能由外部 AI 處理及儲存。刪除單筆長期記憶不會一併刪除原始聊天或所有其他紀錄。正式隱私權政策目前為草稿。
:::

## 音樂播放

除查看佇列外，下列播放操作需要先加入語音頻道；Bot 已連線時，需與 Bot 在同一語音頻道。

| 指令 | 參數 | 用途 |
| --- | --- | --- |
| `/music play` | `query`：YouTube 網址或搜尋關鍵字，必填 | 搜尋歌曲或加入歌曲／播放清單。 |
| `/music queue` | 無 | 在伺服器內查看佇列。 |
| `/music pause` | 無 | 暫停目前播放。 |
| `/music resume` | 無 | 恢復播放。 |
| `/music skip` | 無 | 跳過目前歌曲。 |
| `/music loop` | `mode`：不循環、單曲循環或全部循環，必填 | 設定循環模式。 |

### 播放範例

```text
/music play query: 喜歡的歌曲名稱
```

以搜尋關鍵字加入歌曲時，依畫面提示選擇搜尋結果。外部音源若無法解析或播放，可能需要稍後重試。

## 面板與按鈕

部分功能從 Discord 介面操作：反應身分組使用 Emoji，客服單 v2 從面板按鈕開單，三角洲生產推薦使用詳情按鈕。這些操作不需要另外輸入 Slash Command。

## 找不到指令？

請先閱讀[功能可用範圍](/docs/features#功能可用範圍)，確認伺服器是否已啟用相關功能，以及自己是否位於正確頻道。

## 管理者權限

標示「管理者」的指令允許下列其中一種身分使用：

1. 具有 Discord **Administrator** 權限的伺服器成員。
2. 持有 **Mochi 已授權管理角色**的伺服器成員。

角色名稱叫「管理員」，或只有管理訊息等其他權限，不會自動符合這項檢查。使用者有操作權限，也不代表 Mochi 已具備在目標頻道發送、管理角色或建立頻道的權限。

客服單另有角色規則：開單者可以用關閉按鈕，但 `/ticket-v2 close` 需要管理者或該類客服角色；取得 CSV 則需要管理者。詳細條件見[客服單指令參考](/docs/commands/tickets)。

## 如何填寫指令

在 Discord 輸入指令名稱並從選單選擇 Mochi 的指令，接著填寫顯示的欄位。必填與選填欄位列在各指令的參數表；無參數的指令可直接送出。

頻道、角色與成員欄位，從 Discord 清單選取實際對象；訊息 ID、記憶 ID 與案件編號，則使用面板回覆或案件內取得的值。不要以頻道 ID 代替訊息 ID，或以部分 ID 代替完整記憶 ID。

## 面板與按鈕

反應身分組、客服開單與關閉、音樂面板及製造詳情都提供 Discord 介面操作。功能指南會說明按鈕位置與操作結果；按鈕功能不一定有對應的 Slash Command。

## 找不到指令？

- 先在伺服器內選擇 Mochi 的指令，而非在私訊中查找。
- 若指令未出現在選單，不能只依文件推定你或該伺服器已能使用；也不要改輸入猜測的子指令。
- 指令出現但回覆權限不足，檢查上方的身分條件。
- 設定後沒有預期結果，依該功能指南檢查目標頻道、角色階級或面板狀態。

## `/delta channel`

指定每日臺北時間 08:00 的密碼發送頻道。

| 參數 | 需求 | 說明 |
| --- | --- | --- |
| `channel` | 必填・文字頻道 | 每日密碼要送達的伺服器文字頻道。 |

<dl class="command-access">
  <div><dt>使用權限</dt><dd><a href="/docs/commands#管理者權限">管理者</a>。</dd></div>
  <div><dt>操作條件</dt><dd>Mochi 需能查看並在目標頻道傳送嵌入訊息。</dd></div>
</dl>

**操作方式**：選擇 `/delta channel`，在 `channel` 選取要收到每日訊息的文字頻道。

設定只保存之後的發送位置，不會立即補發；再次執行可更換頻道。
